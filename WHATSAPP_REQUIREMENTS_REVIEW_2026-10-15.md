# Проверка требований сайта THE BASE — 15 октября 2026

## Статус

Правки реализованы и проверены локально. Коммит, push, деплой и удалённая проверка staging пока ожидают выполнения; их результаты будут записаны после публикации. Ограничения исходных данных перечислены отдельно.

Проверка учитывает последние сообщения SEO и прямые указания владельца. Уже правильные элементы сохранены. Пункты, для которых отсутствуют подтверждённые данные или утверждённые материалы, перечислены отдельно.

Цель публикации этой версии — **только staging**. Исходная переписка, её папка, расшифровки, внутренние документы и локальные артефакты обработки не предназначены для GitHub или публичных assets.

## Что изменено в этой версии

### Главная

- Описание первого экрана приведено к последнему варианту макета Home Hero `03407`: ингредиенты для кафе, ресторанов и франшиз, производство в UAE. H1 Premium Beverage Bases сохранён.
- Request samples ведёт на существующую страницу `/ae/request-samples`.
- В блоке производителя и описании Private Label в карусели ресурсов устранены старые числа 20 и 16. Количество берётся из действующего ассортимента — **22 категории**.
- В блоке производителя и footer добавлены три предоставленных утверждённых знака: **HACCP, ISO 22000 и Halal**. Использовано оригинальное изображение каждого знака, без перерисовки или вымышленных сертификатов.
- У All resources убрано подчёркивание, которое создавалось нижней границей, включая hover.
- Из шага Production убрана стоковая линия розлива воды. Оставлен предусмотренный макетом нейтральный слот для фотографии производства.
- В карточке R&D блока Guides and tools используется предоставленное изображение шоурума; из карточки калькулятора убрана неподходящая фотография чужих брендированных капсул.

### R&D и дистрибьюторы

- Из R&D удалены стоковые изображения микроскопа и линии розлива, ранее подписанные как собственная лаборатория/производство THE BASE. Для лаборатории оставлено место под подтверждённую фотографию; первый экран сохраняет тёмную поверхность и существующую структуру.
- Ссылка на образцы готового ассортимента ведёт на `/ae/request-samples`.
- У небольших заголовков и названий шагов R&D/Distributors вес 800 заменён общей ролью **700**, без изменения адаптивных размеров.
- Публичное описание Strategic уточнено: права на территорию могут быть согласованы после пилота, с определённой территорией, каналами, продуктами, обязательствами по продажам и оценкой результатов. Автоматическое предоставление эксклюзивности не обещается.
- Finder описывает **17 рынков, доступных для выбора**, вместо утверждения о 17 уже подтверждённых партнёрах. Контактные данные публикуются по мере подтверждения; для остальных рынков сохранена помощь команды UAE.
- Для неподтверждённых партнёров язык обслуживания также отмечен как ожидающий уточнения. Пустой результат поиска означает отсутствие совпадения в списке, а не доказанное отсутствие партнёра в стране.

### Форма образцов

- Выбор вкусов сделан настоящими checkbox с клавиатурным управлением и видимым состоянием фокуса.
- Для продукта со списком вкусов требуется **от 1 до 3 вкусов**. При снятии всех вариантов отправка блокируется до обращения к API; показывается понятная ошибка. После выбора трёх остальные варианты недоступны, пока один из выбранных не снят.
- Общая форма без выбранного продукта сохраняет возможность отправить запрос без списка вкусов.
- Privacy Policy в drawer стала настоящей ссылкой на `/ae/privacy`.
- После успешной отправки указана команда THE BASE, без обещания неподтверждённой местной команды в стране покупателя.
- Сохранён существующий контракт Free Sample: выбранный продукт и рынок, контактные данные, вкусы/тип бизнеса/город/страна покупателя в сообщении, first-touch UTM, landing/current page и referrer. Подтверждение показывается только после успешной доставки через `/api/leads`.

## Что ещё требует материалов

Эти пункты не объявляются завершёнными:

1. **Происхождение каждого SKU.** Формулировка Country of Origin / Manufactured for зависит от фактического изготовления и упаковки конкретного продукта. Условное сообщение о China не распространяется на весь ассортимент. Для точного применения нужны данные по SKU; презентация Colour Collection сама указывает UAE.
2. **Контакты остальных 16 рынков и переводы.** Подтверждённый местный контакт в материале есть для UAE. Для остальных сохраняется честный pending и связь с UAE; несуществующие country pages/переводы не публикуются.
3. **Настоящие фотографии производства/R&D и недостающих продуктов.** Нужны подтверждённые производственные/лабораторные снимки, отсутствующие pack shots и отдельные serving photos. Одобренная 3D-визуализация помещения не доказывает существование фотографии цеха. Нейтральные слоты не считаются завершённой фотосъёмкой.
4. **Nutrition, аллергены, состав, хранение и инструкции для каждого SKU/вкуса.** Используется только предоставленная таблица с явно указанным вариантом. Другие вкусы не наследуют её цифры; особенно требуют уточнения новые Sauce/Purée/Add-ons/Electrolyte ranges.
5. **Marketing kits и спецификации для скачивания.** Готовые файлы не предоставлены; действуют запросы к команде. Наличие CTA не означает наличие downloadable kit.
6. **Пять черновых вкусов Jam.** Для публичной страницы и формы образцов нужна лабораторная/коммерческая готовность. Исторические commerce SKU требуют отдельного согласования, чтобы не изменить действующий checkout без подтверждения.
7. **Topping.** Нужна единая спецификация выхода готового продукта, рецептуры, размера порции и prepared nutrition: исходные материалы содержат противоречия. Новые числа не выдумывались.
8. **Отдельный утверждённый макет каталога.** Screenshot `03729` показывает отклонённый интерфейс; следующие screenshots относятся к Sitemap. Отдельного HTML с утверждённой новой компоновкой каталога в комплекте нет. Рабочий каталог 22 категорий, фильтры, поиск, сортировка и реальные shop links сохранены; полная перестройка по отсутствующему макету не заявляется.
9. **Основной телефон компании.** Contacts и footer/Organization используют разные уже существовавшие номера. Для единого NAP требуется подтверждение основного номера; номера не заменялись предположением.
